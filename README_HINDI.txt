GRACE IMITATION JEWELLERY — WEBSITE PACKAGE
============================================

DESIGN
- Premium Wine / Burgundy + Champagne Gold + Warm Ivory theme
- Responsive layout for mobile, tablet and desktop
- Grace Imitation Jewellery branding and Jodhpur shop details

CUSTOMER WEBSITE
- Browse products by category
- Search products
- Enquire about an item through WhatsApp
- Shop address, phone and Instagram details

ADMIN PRODUCT MANAGEMENT
1. Open the website and tap “Admin Login”.
2. Demo PIN: 356301
3. Open Products.
4. Enter product name, category, price and description.
5. Select a photo from your phone and tap Add Product.
6. Use Edit or Delete beside any product to manage it.

IMPORTANT LIMITATIONS — PLEASE READ
This ZIP is a front-end demo package. Product information and photos are saved in the browser's local storage on the same device only.
- Changes do NOT automatically appear on other phones or devices.
- This is NOT a secure server-side admin login. The demo PIN is present in the JavaScript file.
- It does NOT provide live order processing, payment processing, a shared customer database, or server backups.
- Do not enter sensitive customer, payment, or personal information.
For a real public online store with secure admin login and shared product catalogue, connect a backend/database and server-side authentication before publishing.

RUN LOCALLY
- Extract the ZIP.
- Open index.html in a modern browser.
- Internet connection is recommended for Google Fonts and WhatsApp links.
